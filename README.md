# Qslides

This is Qslides, a website that mixes up Kahoot and PowerPoint to make presentations with quiz things in it. My focus is on teachers for now, but maybe something else soon :) I try to make all stuff as fun and transparent as possible.

## Framework
- Next.js 13
- Tailwind CSS

## Hosting
Probably on Vercel or something, or self host it. More info here soon.

## Getting Started
1. Clone the repo
2. Run `npm install` and `npm run dev`.
3. Done!
Or you can use the hosted version once it is up.
